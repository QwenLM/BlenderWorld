# README figure sources

These assets come from the source archive for *BlenderWorld: Benchmarking Visual Agents for 3D Creation from Real-World References* supplied on October 14, 2026.

| Web asset | Original paper asset |
| --- | --- |
| `blenderworld-logo.png` | `figures/capybara_blender_no_circle.png` |
| `benchmark-overview.jpg` | `figures/BlenderWorld_Intro_v6.pdf` |
| `dataset-statistics.png` | `figures/blenderworld_223_overview.pdf` |
| `benchmark-construction.png` | `figures/Construction.pdf` |
| `evaluation-pipeline.png` | `figures/BlenderWorld_Evaluation_Pipeline_Futura_v13.pdf` |

The PDF figures are rendered on a white background, trimmed to remove outer whitespace, and resized to 2,200 pixels wide. The mascot is resized to 320 pixels. Figure content and labels are preserved; the overview uses JPEG for a smaller download, while diagrams use PNG for clear text.

The evaluation figure depicts the paper's GPU and Blender MCP setup. See the [public evaluation guide](../evaluation.md) for supported runtimes and the [submission format](../submissions.md) for the current CLI contract.
